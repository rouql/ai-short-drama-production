# 分集视频提示词

## 边界与输入

本阶段只交付分集视频生成提示词和工作人员找图映射，不生成视频，不生成、读取、识别、比较或验收图片。输入只包括通过的正式剧本、导演分解和全剧资产提示词文本；工作人员在本 Skill 之外根据资产提示词生成、选定实际参考图，并在调用视频模型时上传。视频提示词作者只绑定稳定资产槽位，不以“先看图”为开工条件，也不对实际图片质量作结论。

资产提示词与工作人员上传的参考图已经负责锁定人物五官骨相、体态、发型、基础服装与固定配件，场景空间拓扑、建筑结构与固定锚点，道具原型、尺度、结构与基础材质。视频阶段不得再次设计或复述这些静态外观；它负责动作、表演、视线、呼吸、重心、互动、受力、摄影机运动、动态光影、声音和结束状态。

不得新增或改写剧情、人物、地点、关键道具、组织、能力、证据、关系与因果。导演已经批准的非剧情性置景、不具名背景人口、环境声、音乐、视觉效果和等价历史视觉转译属于可执行画面，不得被负面提示词误删。

## 分段

- 先按导演稿的动作任务、连续性和视频模型能力分段，不把每个导演镜头机械等同于一个视频片段。
- 用户指定模型或时长上限时，严格按其能力拆分；未指定模型时，根据动作复杂度、对白长度、角色并发、接触物理和镜头运动保守分段，不预设统一15秒，也不为追求时长利用率硬塞动作。
- 同场景、同轴线、同光声、动作因果连续且可由一种主要摄影任务完成的相邻镜头可以合并；发生空间跳转、时间跳转、复杂受力切换、关键状态突变或生成风险过高时拆段。
- 每段只承担一个主要动作任务。一个段内只保留一种主要摄影机运动；复杂动作按“启动—接触—受力—结果—余波”拆开并闭合。
- 不为凑时长添加停滞、无依据慢动作、重复反应或剧本外动作。

## 参考图片映射

每个片段从`@图片1`重新编号，连续无空号；同一图片号只对应一个全剧稳定资产槽位。槽位类别与前缀必须匹配：人物用`@人物Pxx-名称`、场景用`@场景Sxx-名称`、道具用`@道具Dxx-名称`、特效用`@特效Fxx-名称`。映射写资产名称和槽位，不写“已经看见图片里有什么”，不描述图片质量，也不在正文重复静态外观。

```markdown
【参考图片】
@图片1=@人物P01-林瑞
@图片2=@场景S03-仿真城站台
@图片3=@道具D02-腕环
```

正文只用控制关系调用图片，例如“人物身份与基础定妆由@图片1锁定，站台空间拓扑由@图片2锁定，腕环结构由@图片3锁定”。禁止把人物脸型、五官、发型、身材、基础服装，场景建筑与布局，道具基础结构重新写一遍；只有本段发生的临时状态变化，如衣料被雨打湿、伤势加重、道具破损、灰尘沾染，才作为动态结果写入。

## 固定模块与顺序

每个片段必须完整、自包含，并按以下顺序各出现一次；六个模块都必须有实际内容，只有标题没有正文不算通过：

1. `【参考图片】`
2. `【风格】`
3. `【视频提示词】`
4. `【对白与声音】`
5. `【负面提示词】`
6. `【结束状态】`

工作人员复制任意单段时，不需要从文件开头、上一段或其他文件补齐文字模块。不得建立整集公共风格或`【声音总则】`让片段引用。

## 每片段风格模块

`【风格】`是强制模块，不能删除、合并进参考图片或缩成“电影感”。它负责统一视频模型不会仅凭静态参考图自动锁定的动态视觉语言：

- 全剧稳定媒介：真人写实、动画、半写实 3D 或用户冻结的其他媒介。
- 全剧摄影与成像语法：镜头观察距离、运动克制程度、景深倾向、颗粒/锐度、空气透视与材质呈现方式。
- 全剧受控色彩系统，以及本场已经确定的暖冷关系；不得在同一场景中无理由忽冷忽暖。
- 本段真实光源、方向、软硬、色温、动态变化和互动光；光线变化必须有场内动因并继承前段状态。
- 本段空气、天气、材质响应、节奏压力与摄影运动质地，以及与上一片段的连续关系。

风格模块不得重新描述或改造人物五官骨相、体型、发型、基础服装、固定配件、场景建筑与拓扑、道具基础结构。它可以说明“低饱和土色体系、火光为暖色动机光、手持轻微呼吸感、粗织物与夯土不过度磨皮”等动态成像和材质呈现规则，但不能另造一张脸、一套衣服或一处空间。不得写互斥候选方案、软件教程、参数清单或“4K、顶级、震撼、大师作品”等空词。

## 视频提示词主体

`【视频提示词】`只写本段随时间发生的内容，采用可执行顺序：

1. 开始状态：人物位置、朝向、视线、持物、伤势、光声和上一段继承状态。
2. 触发：谁先看见、听见、决定或受力。
3. 主动作：步幅、重心、手部路径、接触点、阻力与先后。
4. 反应与结果：表情肌、呼吸、吞咽、视线转移、距离变化、物体重量、材质响应和可见后果。
5. 摄影机：一种主要运动，写清起点、路径、跟随对象和停止点；固定机位也写清保留关系。
6. 动态光影与效果：只写本段发生的光影、天气、尘雾、液体、破坏或特效变化，并说明来源和作用对象。

多人反应错开先后，不整齐同步。接触动作必须闭合为启动、接触、受力/阻力、后果与材质响应。人物反应不得早于刺激，掉落物、污渍、破坏、伤势和持物不能在段尾自动复位。

## 对白与声音

`【对白与声音】`每段独立完整：

- 有对白时逐字写出说话人、台词、画内/画外、口型可见范围和发声时机；无对白明确写“无对白”。
- 写本段真实环境底床、方向、距离和空间反射。
- 写与动作同步的拟音、呼吸、衣料、脚步、器物受力和材质声。
- 导演已确定的音乐写入进入点、强弱变化、与对白的让位及段尾声态；没有获准音乐时不擅自添加。
- 导演已批准的不具名背景人口只能保留无语义、不可识别的声场，不得新增可辨台词、信息或集体立场。

声音不能提前宣布画面尚未发生的结果。段尾写清声音是切断、延续、远去还是作为下一段声音桥。

## 负面提示词

`【负面提示词】`只拦截模型可能擅自增加或破坏的内容，不得删除剧本和导演已经批准的内容。每段至少包含：

- 禁止自动字幕、水印、标题、标识和无依据可读文字。
- 禁止新增未获批准的具名角色、可识别人声、关键道具、剧情行动、关系与信息。
- 禁止人物身份漂移、参考图冲突、基础定妆改造、脸部突变、服装基础版无故变化。
- 禁止场景拓扑漂移、道具结构变形、持物穿插、肢体畸形、错误口型、物理复位和无来源光效。
- 禁止与本段摄影任务冲突的乱切焦段、镜头瞬移、无依据慢动作和多重主运镜。

导演已批准的普通置景、不具名背景人口、环境声、音乐和效果不属于“新增”，不得用“禁止额外人物/物件/声音/特效”等笼统语句一刀切。负面项必须在语义上把禁项限定为未经剧本或导演确认的新增，并保留已批准内容；可以使用任何清楚等价的自然表达，不要求照抄固定句子。

## 固定交付格式

每集一个 Markdown，文件名`E001-视频生成提示词.md`。正文示例：

```markdown
# 第1集视频生成提示词

【片段V1｜约8秒】
【参考图片】
@图片1=@人物P01-林瑞
@图片2=@场景S03-仿真城站台

【风格】
全剧真人写实、低饱和受控色彩与克制观察式摄影；本段延续站台冷白顶光，人物移动时金属地面反射只随真实光源轻微滑动，空气微尘和手持呼吸感保持前段强度，不改写@图片1定妆与@图片2空间结构。

【视频提示词】
开始时林瑞站在黄线外，目光落向关闭的车门。提示音响起后，他先收住半步，右手从身侧抬向腕环却在接触前停住；摄影机从其右后方中景缓慢横移半个身位，始终保留车门与他的视线关系，在他抬眼看向门缝时停止。门缝冷光扩大，光只扫过他的指节和侧脸，他呼吸变浅，重心退回后脚。

【对白与声音】
无对白。站台远端低频通风声持续；提示音来自画面左前方，门机启动声与缝隙扩大同步；林瑞衣袖摩擦和一次短促吸气位于近场。段尾门机声继续，作为下一段声音桥。

【负面提示词】
禁止字幕、水印、标题和无依据文字；禁止未经剧本或导演确认的新增角色、物件、对白、音乐和特效；保留导演批准的远景候车人影与站台环境声；禁止人物身份和基础定妆漂移、场景拓扑变化、肢体穿插、车门结构变形、错误口型、镜头瞬移和无来源光效。

【结束状态】
林瑞右手停在腕环上方，重心在后脚，视线锁住扩大的门缝；车门尚未完全打开，冷光和门机声继续。
```

文件末尾必须且只能出现一次`【工作人员找图清单】`，只列片段、图片编号、资产名称和全剧槽位，不附图片、不要求本阶段看图。清单必须逐项覆盖正文每个片段的全部参考图片映射，片段号、图片号和稳定槽位完全一致，不能遗漏、增加或改绑：

```markdown
【工作人员找图清单】
片段V1｜@图片1=@人物P01-林瑞
片段V1｜@图片2=@场景S03-仿真城站台
```

## 视频检查

1. 所有剧本动作、反应、关键声音和对白是否有片段归属。
2. 参考图编号是否从1连续并绑定类别前缀正确的稳定资产槽位；文件末尾工作人员找图清单是否唯一、完整并与正文逐项一致；是否没有声称看图、审图或生成图片。
3. 是否按模型能力和动作容量分段，没有机械套统一15秒或把导演每镜切成一段。
4. 每段是否只有一个主要动作任务和一种主要摄影运动，接触物理、刺激与反应顺序是否闭合。
5. 每段`【风格】`是否保留全剧媒介、色彩和摄影语法，写清本段暖冷、真实光源、材质、空气与连续状态。
6. 风格和视频主体是否没有重新设计人物五官、体态、发型、基础服装、场景拓扑与道具结构。
7. 视频主体是否只写动作、表演、视线、重心、互动、摄影、动态光效和结果，并与参考图职责清楚分工。
8. 对白是否逐字、说话人和口型边界正确；声音、音乐、背景人口和效果是否继承导演批准内容。
9. 相邻片段的人物位置、持物、伤势、破坏、光源、声音和物理状态是否连续。
10. 负面提示词是否禁止未经批准的新增，而没有误删导演批准的置景、背景人口、音乐、环境声和效果。
11. 每段是否完整包含六个固定模块，模块顺序和结束状态闭合。
12. 是否只输出文本提示词与槽位清单，没有生成、读取、比较或验收实际图片和视频。

交付前执行 [轻量发布门](quality-gate.md) 的通用检查和`V`阶段检查；写入新视频提示词后运行`scripts/validate_video.py <视频提示词路径>`。审查尚未使用稳定资产槽位的旧提示词时可运行`scripts/validate_video.py --legacy <视频提示词路径>`，允许旧式参考图名称映射，但不把旧格式自动认证为新合同。脚本只检查文本结构、模块非空、模块顺序、参考图编号与基础负面项，不调用模型、不读取媒体、不生成审查报告。
